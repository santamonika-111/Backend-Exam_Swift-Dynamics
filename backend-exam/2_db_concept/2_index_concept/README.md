## Response Section
Data Indexing
ข้อดี
    - ดึงข้อมูลมาใช้ได้ทันที
    - เชื่อมข้อมูลไวขึ้น
    - จัดกลุ่มได้ไวขึ้น
    - ใช้ Unique Character ตรวจเช็คความซ้ำซ้อนได้
    - ลดการทำงาน Hardisk(I/O)

ข้อเสีย
    - ข้อมูลต้องอัพเดทตลอดเวลาเมื่อมีการเปลี่ยนแปลง
    - Index จะกิยพื้นที่มากเมื่อแยก Index ออกเรื่อย ๆ
    - ประสิทธิภาพข้อมูลจะลดลงเมื่อทำ Index มากเกินไป
